# Security Policy

## Reporting a vulnerability

Use a private channel already agreed with the repository maintainer for
security-sensitive reports. If no such channel is available, open an issue
asking for a private contact channel without including vulnerability details.
Do not disclose credentials or vulnerability details in public issues.

No dedicated security team or response-time commitment is established for
this candidate-maintained source submission. Voxgig is the generator vendor;
it is not presented as the security contact for this repository.

For non-security bugs, use the issue tracker: https://github.com/angle-theory-studio/tally-sdk/issues

## Scope

This policy covers the TypeScript source in this repository. No npm package
or other language package has been published as part of this submission.

This is an unofficial SDK for the Tally public API, generated by
Voxgig. It is not affiliated with, endorsed by, or sponsored by the upstream
API provider.
